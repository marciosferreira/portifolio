O Orquestrador roteia pedidos para dois sub-agentes ReAct — Analista (análise ad-hoc, gráficos, PDFs, Excel) e Scheduling (CRUD de tarefas agendadas). Um StateGraph determinístico escreve, testa em sandbox e versiona o código Python das tarefas, com auto-correção de até 3 tentativas. Um Daemon verifica e executa as tarefas a cada 60s. Persistência em SQLite, streaming via SSE, observabilidade via Langfuse.

Live Demo · Servidor MCP Real + LLM

MCP Agent — Demonstração Real

Um servidor MCP Python real expõe 4 ferramentas industriais. Digite uma pergunta (ou clique num chip) — o LLM decide qual tool chamar e com quais argumentos, o servidor executa e retorna dados dinâmicos de verdade.

API REST tradicional

  • Quem chama é seu código — você escolhe o endpoint e monta a requisição
  • Schema documentado para humanos (OpenAPI, README)
  • Resposta vai para o seu código, que decide o que fazer com ela
  • Integração manual a cada novo modelo ou fluxo

MCP Server

  • Quem chama é o LLM — ele lê o schema e decide sozinho qual tool usar e com quais argumentos
  • Schema exposto em tempo de execução via list_tools(), legível por máquina
  • Resposta vai direto ao contexto do modelo, que gera a resposta final
  • Um servidor, qualquer modelo compatível (Claude, Gemini, GPT…)
